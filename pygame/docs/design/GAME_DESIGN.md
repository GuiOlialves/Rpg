# Game design — O Vale

## Escopo atual

RPG 2D top-down com exploração, combate, progressão por atributos/equipamentos, missão inicial e três regiões conectadas.

## Sistemas existentes

Movimentação, ataque, dash, inimigos, diálogos, inventário, equipamentos, progressão, missões e save/load. Este documento não propõe mudanças de mecânicas.
